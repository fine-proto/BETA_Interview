# FINE Alaseo 베타 사전 인터뷰

FINE Alaseo 베타테스트에 앞서 진행한 테스터 사전 인터뷰(프로토타입 사용 + 1:1 인터뷰)의 요약·분석 페이지입니다.

- **전체 요약 분석**: 핵심 발견, 기능별 반응(자동 집계), 사용자 유형, 기획 반영 후보, 베타에서 확인할 것, 사전 사용자 경험 기준선(Baseline)
- **인터뷰이 목록**: 인터뷰 일시·소요 시간·구분(본 인터뷰/리허설)
- **인터뷰별 요약**: 프로필, 기능별 반응, 종합 평가, 분석, 인상적인 발언, 기준선
- **설문**: 인터뷰 직후 설문(사용 의향·기능 관심도)과 인터뷰 전 사전 설문 (인터뷰를 마친 테스터만, 연령대·시군구 단위로 표기)
- **원문 보기**: 비식별 처리된 녹취 원문, 검색·화자 필터

원문의 진행자는 '진행자', 그 외 실명은 성+OO로 표기했습니다. 녹취 자동 변환본이라 인식 오류가 있을 수 있습니다.

인터뷰 추가 방법은 [CLAUDE.md](CLAUDE.md)를 참고하세요.
